# Tunisian Trilingual Technical Code-Switching Evaluation

This dataset contains parallel technical prompts in English, French, Modern
Standard Arabic, and Tunisian trilingual code-switched Arabizi.

## Status

This is an evaluation dataset currently containing 66 items across circuits,
mathematics, algorithms, debugging, networking, and physics. Before public
submission, the maintainer must document human review of dialect naturalness,
translation equivalence, answer correctness, and code-switch placement.

## Intended use

Use this dataset to measure whether a language model preserves technical
answers under controlled language mixing. It is not a general-purpose Tunisian
Arabic corpus and should not be treated as representative of all Tunisian
speakers.

## Limitations

The current schema does not yet contain switch-location, Arabizi-density,
difficulty, or human-review annotations. These should be added before making
strong claims.
